# Simulation2024
This is the repo for _Best Practices for Modeling Arthropod Lifetimes in a Bayesian Framework_ (https://www.biorxiv.org/content/10.64898/2025.12.16.694707v1)

File Descriptions:
1. Code > Exponential_Data > Lifetime_Sim_Code_Narrow.R: This file contains the setup and 5 simulations using the 5 different forms of data generated from an exponential distribution with a narrow temperature interval. In addition to running the simulations, this file calculates the RMSE, creates figures showing how the extreme temperatures were calculated, and creates figures comparing the fitted TPC (median lifetime or mortality rate) between the different data transformations.
2. Code > Exponential_Data > Lifetime_Sim_Code_Wide.R: This file contains the setup and 5 simulations using the 5 different forms of data generated from an exponential distribution with a wide temperature interval. In addition to running the simulations, this file calculates the RMSE, creates figures showing how the extreme temperatures were calculated, and creates figures comparing the fitted TPC (median lifetime or mortality rate) between the different data transformations.
3. Code > Weibull_Data > Lifetime_Sim_Code_Narrow_Weibull.R: This file contains the setup and 6 simulations using the 5 different forms of data generated from a Weibull distribution with a narrow temperature interval. In addition to running the simulations, this file calculates the RMSE, creates figures showing how the extreme temperatures were calculated, and creates figures comparing the fitted TPC (median lifetime or mortality rate) between the different data transformations.
4. Code > Weibull_Data > Lifetime_Sim_Code_Wide_Weibull.R: This file contains the setup and 6 simulations using the 5 different forms of data generated from a Weibull distribution with a wide temperature interval. In addition to running the simulations, this file calculates the RMSE, creates figures showing how the extreme temperatures were calculated, and creates figures comparing the fitted TPC (median lifetime or mortality rate) between the different data transformations.
5. Code > temp-independent-sim.R: This file contains the code for the simulation comparing the effects of inverse transformations on the data (S2 of the Supplementary Material).
6. Comparisons > Lifetime_Sim_Collective.R: This file contains the code to create the majority of the figures provided in the main manuscript, as well as those in the Supplementary Material, for the simulations using data from a wide temperature interval (both those using data generated from an exponential distribution and those using data generated from a Weibull distribution).
7. Comparisons > Lifetime_Sim_Collective_Narrow.R: This file contains the code to create the majority of the figures provided in the Supplementary Material illustrating the simulations using data from a narrow temperature interval (both those using data generated from an exponential distribution and those using data generated from a Weibull distribution).
